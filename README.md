# Gokulnath N - Portfolio

A single-page HTML/CSS/JavaScript portfolio for Machine Learning, Computer Vision and MLOps roles.

## Files

- `index.html` - portfolio content
- `style.css` - responsive design
- `script.js` - mobile navigation and year
- `assets/resume.pdf` - add your latest resume here

## Before publishing

1. Copy your latest resume into `assets/` and name it `resume.pdf`.
2. In `index.html`, replace `YOUR_EMAIL@example.com` with your email.
3. Open `index.html` locally to test.
4. Create a GitHub repository named `GOKULNATH152.github.io`.
5. Upload the files.
6. Enable GitHub Pages from Settings -> Pages -> Deploy from branch -> `main` -> `/root`.
